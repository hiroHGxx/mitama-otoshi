# 御霊おとし 仕様書

『月蝕綺譚 -Luna Occulta-』二次創作の落ち物パズルゲーム。
本書は 2026-08-19 時点の実装仕様。

## 1. ゲーム概要

- ジャンル: スイカゲーム式 落ち物パズル（物理合体）
- プラットフォーム: モバイルブラウザ優先の Web（PC も可）
- 遊び方: なぞって狙い、離して御霊を落とす。同じ御霊が触れると「浄化」されて一段上の御霊に合体。壺からあふれたらゲームオーバー（＝夜明け）
- 世界観の言い回し: 公式コピーの文体に準拠（読点リズム・「夜明け＝終わり」の逆転・「もう一夜」等）
- ビジュアル: 公式トンマナ「宵闇に金 — 蒔絵の夜」の実装トークンに準拠（公式MCP `kitan-lore` の get_design_tone で取得）。宵闇藍 #131320 / 金泥 #D9A94C・#F0CE7E / 月白 #E8E4D8 / 蝕紅 #E0562F（警告と高揚のみ・面積5%以下）/ 暗紫 #8E6B9E（夜桜）

## 3. 連鎖（因果ベース）

- 合体で生まれた玉は「親の連鎖深度+1」を継承し、生まれて **1.6秒（CHAIN_HOT_MS）** の間だけ「熱い」状態
- 熱い玉が関与した合体だけ連鎖が伸びる。プレイヤーが落とした玉は深度0なので、**タップ連打の同時多発浄化は連鎖にならない**（純粋なカスケードのみ）
- 深度2以上で盤面右肩に縦書き金文字「二連浄化」〜「十連浄化」（掛け軸ふうに現れて消える）＋金の粒が増える
- 琴の音が連鎖のたびに陰旋法のまま音階を駆け上がる（+2段/連鎖・上限+8、3連鎖以降は3音目のきらめき追加）

## 4. 盤面・物理

- 論理座標: 480×720（DPR≤2 でスケール描画、`main` 要素の実寸にフィット）
- 壺の内寸: x 46〜434（388px）。物理壁は画面上端まで延長（縁乗り防止）し、厚み80pxで貫通防止
- 物理: Matter.js 0.20。sleeping **無効**。壁摩擦 0.08、玉は restitution 0.12 / friction 0.25 / density 0.0012
- 合体判定: `collisionStart` と `collisionActive` の両方。合体直後の玉は 230ms 合体しない＋誕生ポップ
- ゲームオーバー: 負け線（y=146）より上で速度 0.35 未満が 2 秒継続。落下直後 1.2 秒は猶予
- 演出中（カットイン・皆既月蝕）と図鑑オープン中は物理を完全停止

## 5. 演出

- **オープニング**: 札絵（**ランク10**・ランダム1枚）をフルスクリーンでズームアウト → 夜の帳 → 案内カード。カードのタイトルは金グラデ文字＋背後に蝕環
- **満月成就**: 公式必殺カットイン（**正装・晴れ着・浴衣の3種からランダム**・アニメwebp）が黒帯上を**左→右**へスライド（絵が右向きのため前進方向）。1.75 秒停止
- **皆既月蝕**: 暗転 → 血月イラストパンチイン → **蝕環（喰われた筆円相）が血月を抱く** → 火の粉 → 金グラデ調の「皆既月蝕」大文字（e-zoom）→ シェイク。計 2.4 秒停止
- **蝕環**: 公式の視覚的署名（深紅の筆円相・約1/3欠け）。タイトルカード背後・皆既月蝕・ファビコンで一貫使用
- **月の満ち欠け**: 背景の月が最高到達段に応じて満ちる
- **環境演出**: 蒔絵調の生成背景（上縁に金雲・金花紋、両脇に金泥の細流と深紅の花びら、中央は無地の宵闇）、暗紫の桜の花びら、**闇を昇る金の塵**、ビネット
- **満月の後光**: 盤面の満月玉に脈動する金の暈（reduced-motion時は静的）
- **スコア**: M PLUS Rounded 1c、カウントアップ＋加点時ポップ
- **ゲームオーバー**: 「夜が明けた」（蝕紅）＋称号＋最高到達キャラのランク10札絵＋スコア

## 6. 御霊図鑑・称号

- **図鑑**: 下部の階梯アイコンをタップで開閉（羽二重スタイルのカード・開いている間は物理停止）。ランク10札絵＋名前・よみ＋所属/五行＋公式紹介文（MCPの公開設定）。‹ › で移動
- **解禁**: 1〜5段は最初から閲覧可。6段以上は到達した段位まで（`mitama_dex_max` に永続）。未到達はシルエット＋「？？？」
- **称号**: そのプレイの最高到達で決まる10種（宵の口→夜歩きの見習い→夜歩きの手習い→浄化の手練れ→浄夜の導き手→五行の使い手→夜番の頭→月導の行者→緋桜の同志→満月成就）。皆既月蝕を見届けたプレイは別格「蝕を見届けた者」。最高の誉れは保存され（`mitama_title`/`mitama_title_rank`）タイトル画面に「これまでの誉れ」として表示

## 7. 音

- BGM: 公式メインテーマ AAC 80kbps。音量 0.16。ループ
- **琴（浄化・満月・皆既月蝕）**: 実サンプル再生。AI生成の琴独奏曲（Lovart）から切り出したワンショット2種（`koto_pluck_main.m4a`=G3単音 196.5Hz、`koto_pluck_high.m4a`=高音装飾句・固定ピッチ1.12倍で再生）。単音を playbackRate 変速で陰旋法（都節）に展開、step 11（932Hz）上限でオクターブ折り返し。毎回音量±8%・ピッチ±0.4%の揺らぎ、変速率2.5超は下オクターブを40%で重ねる。装飾句は3連鎖以上と満月成就で鳴る。デコード完了までは Karplus-Strong 合成でフォールバック
- 拍子木・鈴・太鼓は WebAudio 合成のまま（拍子木＝帯域ノイズ）。200Hz 未満の純音は使わない
- **鈴**: 盤面に満月がある間、約2.6秒おきに倍音3層の「ちりん」が薄く鳴る
- 音の入口: 「月夜に入る（音あり）」「静かに入る（音なし）」の2択（localStorage記憶）。ゲーム中は ♪ で切替
- バックグラウンド: visibilitychange で BGM 停止、復帰で再開

## 8. 入力・iOS対策

- pointermove で照準、pointerup で落下（クールダウン 550ms）
- iOS Safari のダブルタップズームを JS で抑止（350ms 以内連続タップの2回目を preventDefault・ボタン除外）、ピンチは `gesturestart` を preventDefault

## 9. テスト・デバッグ機能

- `#autotest`: 自動で落とし続ける（タイトル自動スキップ）
- `#test`: 開始後に咲耶ペア×2 を自動投下
- **タイトルロゴ（ヘッダーh1）3回タップ**（1.5秒以内）: 手持ちの玉が咲耶になる（撮影・デバッグ用の隠し機能）

## 10. アセットとビルド

- 顔アイコン: 公式配布の顔アイコン(透過)（`scripts/build-faces.sh` が取得 → 段位ごとの実寸に縮小 → `src/faces.js` へ data URI 化）。玉が使う画素は最大でも r*4 なので、段位ごとにサイズを変えて重さを抑えている
- 札絵: **各キャラのランク10**（素材蔵は各キャラ 01〜10 の10段階ある。URLは台帳 index.json の url を使うこと — `fuda/`・`fuda/app/`・`fuda/v2/`・`fuda/v3/` が混在）
- カットイン: 咲耶3衣装（s5=フィニッシャー）。素材蔵には各キャラ5種・咲耶のみ15種ある
- 盤面背景: Lovart生成（ランク10札絵を参照渡し・「中央70%は無地の宵闇」制約）
- ビルド: `node scripts/build-dist.js` → index.html（単一ファイル・遅延アセット）/ dist/artifact.html（全埋め込み・約14MB）
- 動画: `scripts/preview/choreo2.js`（わいわいタウン用プレビュー動画・640×640）、`scripts/pv/`（PV制作パイプライン・720×1280、assemble.sh 参照）
