# 御霊おとし 仕様書

『月蝕綺譚 -Luna Occulta-』二次創作の落ち物パズルゲーム。
本書は 2026-08-18 時点の実装仕様。

## 1. ゲーム概要

- ジャンル: スイカゲーム式 落ち物パズル（物理合体）
- プラットフォーム: モバイルブラウザ優先の Web（PC も可）
- 遊び方: なぞって狙い、離して御霊を落とす。同じ御霊が触れると「浄化」されて一段上の御霊に合体。壺からあふれたらゲームオーバー（＝夜明け）
- 世界観の言い回し: 公式コピーの文体に準拠（読点リズム・「夜明け＝終わり」の逆転・「もう一夜」等）

## 3. 盤面・物理

- 論理座標: 480×720（DPR≤2 でスケール描画、`main` 要素の実寸にフィット）
- 壺の内寸: x 46〜434（388px）。物理壁は画面上端まで延長（縁乗り防止）し、厚み80pxで貫通防止。描画の壁と物理の内面は2pxの余白で一致
- 物理: Matter.js 0.20。sleeping **無効**（壁で眠って「刺さる」不具合対策）。壁摩擦 0.08、玉は restitution 0.12 / friction 0.25 / density 0.0012、iteration 10/8
- 合体判定: `collisionStart` と `collisionActive` の両方（合体ロック中に接触したペアの取りこぼし防止）。合体直後の玉は 230ms 合体しない（連鎖の各段を見せるため）＋誕生ポップアニメ
- ゲームオーバー: 負け線（y=146）より上で速度 0.35 未満が 2 秒継続。落下直後 1.2 秒は猶予
- 演出中（カットイン・皆既月蝕）は物理を完全停止し、落下操作も無効

## 4. 演出

- **オープニング**: 札絵（公式 fuda ランク8・ランダム1枚）をフルスクリーンでズームアウト表示 → 2.6 秒後に夜の帳が降りて案内カード。タップでスキップ可
- **満月成就**: 公式必殺カットイン（アニメwebp）が黒帯上を右→左へスライド（1.7 秒）。金フラッシュ・琴のかき鳴らし＋高音のきらめき。ゲーム停止 1.75 秒
- **皆既月蝕**: 暗転 → AI生成の血月イラスト（咲耶見上げ構図）がパンチイン → 金の火の粉16粒が舞い上がる → 「皆既月蝕」金文字 → 盤面シェイク。計 2.4 秒停止。音は柝（チョン、チョン）→ 琴の下降フレーズ → 低弦二連 → 高音一撃
- **月の満ち欠け**: 背景の月が最高到達段に応じて新月→満月に満ちる（リトライでリセット）
- **環境演出**: 生成背景（上部のみ金雲・両端桜影・中央は無地の闇）、桜の花びら（最大7枚・reduced-motion で無効）、ビネット
- **ゲームオーバー**: 「夜が明けた」＋最高到達キャラの札絵を金縁で掲出＋スコア

## 5. 音

- BGM: 公式メインテーマを AAC 80kbps に再圧縮（2.2MB）。音量 0.16。ループ
- SFX: すべて WebAudio 合成。琴＝Karplus-Strong 弦モデル、音階＝陰旋法（都節）、拍子木＝帯域ノイズ。**200Hz 未満の純音はスマホスピーカーで再生されないため使わない**（倍音の豊かな弦音で代替）
- 音の入口: タイトルで「月夜に入る（音あり）」「静かに入る（音なし）」の2択。選択は localStorage に記憶。ゲーム中は ♪ ボタンで切替
- バックグラウンド: visibilitychange で BGM 停止・AudioContext suspend、復帰で再開（pagehide でも停止）

## 6. 入力・iOS対策

- pointermove で照準、pointerup で落下（クールダウン 550ms）
- iOS Safari は viewport の `user-scalable=no` を無視するため、ダブルタップズームを JS で抑止（350ms 以内の連続タップの2回目を preventDefault、ボタンは除外）、ピンチは `gesturestart` を preventDefault

## 7. テスト・デバッグ機能

- `#autotest`: 自動で落とし続ける（タイトル自動スキップ）
- `#test`: 開始後に咲耶ペア×2 を自動投下（満月成就→皆既月蝕のデモ）
- **タイトルロゴ3回タップ**（1.5秒以内）: 手持ちの玉が咲耶になる（本番にも隠し機能として存置）

## 8. アセットとビルド

- 顔アイコン: 正典ちびシートの「上段立ち絵の頭部」から `scripts/crop-faces.sh` で切り出し（キャラごとに座標校正済み。目の中間点＝クロップの 50%, 48%）。シート原本はリポジトリに含めず、ビルド時に公式素材蔵から取得
- 札絵/カットイン/生成画像: `assets/art/`。`src/art.js` が URL を持ち、Pages では遅延読み込み
- ビルド: `node scripts/build-dist.js`
  - `index.html`（リポジトリ直下）: **単一ファイル**（JS全インライン）。HTMLとJSのキャッシュずれを構造的に防ぐ。BGM・札絵は外部ファイル参照（初回ロード約660KB）
  - `dist/artifact.html`: Claude Artifact 用の完全自己完結版（全アセット data URI、約9MB）
- OGP: `scripts/ogp-card.html` → Chrome ヘッドレス2xで `ogp.png`（2:1）。og:image はキャッシュバスター付き（?v=N）
