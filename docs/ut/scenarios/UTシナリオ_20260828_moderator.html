0. 目的・範囲・前提

  • 対象ユーザー: リンクを踏んで初めて来た人。『月蝕綺譚』を知らない可能性がある。落ち物パズルの経験はあるかもしれないが、本作固有のルール（浄化・連鎖・皆既月蝕・図鑑・称号）は知らない。
  • 対象ジャーニー: 開く → 何のゲームか分かる → 入る → 落とす → 合体させる → 進みを知る → 調べる → 見せ場に届く → 終わる → もう一度。
  • 対象外: 物理挙動のチューニング（気持ちよさ）、スコアバランス、二次創作ガイドライン適合（別工程）、PV・わいわいタウン掲載ページ。
  • 実施環境: このリポジトリを python3 -m http.server 8971 で配信したもの。本番 origin（github.io）では実施しない——本番の localStorage がオーナーの実記録（最高得点・図鑑解禁・称号）だから。ローカル origin は同時に「初見の状態」でもある。
  • 受入の正本: docs/SPEC.md（節番号で追跡）。
実施順の逸脱について（明示）: 設定の execution.order は非破壊→可逆変更→不可逆の順だが、 本作は入口（A-2）を通らないと盤面に入れない単一の遊び体験であり、体験順に実施する。 可逆変更は localStorage の5キー（mitama_best / mitama_sound / mitama_dex_max / mitama_title_rank / mitama_title）に限られ、UT用 origin ごと捨てられる。 不可逆・外部影響の操作はこのゲームに存在しない（通信をしない）。
